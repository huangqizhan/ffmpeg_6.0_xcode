## 🔍 核心概念速查

### H.264编码流程
```
原始帧 → 宏块划分 → 预测(帧内/帧间) → 变换 → 量化 → 熵编码 → NAL单元 → 码流
                                          ↓
                                    反量化+反变换
                                          ↓
                                      重建帧(参考帧)
```

### NAL单元类型
| 类型 | 名称 | 说明 |
|------|------|------|
| 1 | Slice | 非IDR图像切片 |
| 5 | IDR Slice | 关键帧切片 |
| 6 | SEI | 补充增强信息 |
| 7 | SPS | 序列参数集 |
| 8 | PPS | 图像参数集 |

### 宏块类型
- **I宏块**: 帧内预测，不依赖其他帧
- **P宏块**: 前向预测，参考前面的帧
- **B宏块**: 双向预测，参考前后的帧

### 预测模式
- **帧内**: 4x4(9种)、8x8(9种)、16x16(4种)
- **帧间**: 16x16、16x8、8x16、8x8及子划分

### 熵编码
- **CAVLC**: 上下文自适应变长编码（Baseline/Main）
- **CABAC**: 上下文自适应二进制算术编码（Main/High，效率高10-15%）

## 🛠️ 调试工具

### Xcode调试
```c
// 推荐断点位置
libx264.c:X264_frame()           // 编码入口
h264dec.c:h264_decode_frame()    // 解码入口
h264_slice.c:decode_slice()      // Slice解码
h264_mb.c:ff_h264_hl_decode_mb() // 宏块重建
```

### 命令行工具
```bash
# 编码测试
ffmpeg -i input.mp4 -c:v libx264 -crf 23 output.h264

# 分析码流
ffprobe -show_frames -show_packets output.h264

# 播放测试
ffplay output.h264

# 查看详细信息
mediainfo output.h264
```

## 📝 常见问题

### Q1: 如何在Xcode中编译运行示例代码？
A: 参考项目中的构建配置，或使用命令行：
```bash
gcc h264_debug_example.c -I./ffmpeg-6.0 -L./build/lib \
    -lavcodec -lavutil -o h264_test
./h264_test output.h264 libx264
```

### Q2: 如何查看编码后的NAL单元？
A: 使用十六进制编辑器，查找起始码 `00 00 00 01`

### Q3: 为什么我的断点没有触发？
A: 确保：
1. 编译时启用了调试符号（-g）
2. 没有使用优化（-O0）
3. 断点设置在实际执行的代码路径上

### Q4: 如何比较不同编码参数的效果？
A: 使用PSNR/SSIM指标：
```bash
ffmpeg -i original.mp4 -i encoded.mp4 -lavfi psnr -f null -
```
